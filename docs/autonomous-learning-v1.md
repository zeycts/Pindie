# Autonomous Learning v1 — approved architecture

**Status: approved architecture contract; Slice 1 clean Work Plane and Foundation F1 storage/contracts implemented, remaining Foundation runtime isolation/preemption and Learning Plane behavior pending.** Current production behavior, including this completed slice, is described by `architecture.md` and `behavior.md`; remaining migration is pending. The frozen SI v0.6/v0.7 and CPL v0.1/v0.2 documents describe legacy artifacts and trust during migration, not v1's future autonomy rules.

## 1. Boundary, purpose, and success

Autonomous Learning v0.1's same-Run signal, completion disposition, post-settlement admission and optional immediate learning Run are **rejected as the future architecture**. No per-Task reflection, judgment, or checkpoint belongs in normal execution. Delete that path during migration, not before replacement is safe. Git history retains its old design.

Goal: turn bounded factual Experience from real Human work into falsifiable advisory Strategy hypotheses; test them on suitable future real work, independently evaluate, autonomously trust or reject routine advisory knowledge, and revise it when reality changes. Success is observable changed future work with exact attribution and reversible trust, not candidate count, self-reported improvement, or an invented score. Non-goals: changing model weights, synthesizing fake Tasks, deciding user goals, automating consequential actions or Human Gates, expanding capabilities, creating a second Agent Loop, persisting hidden reasoning/transcripts, or guaranteeing causal efficacy from sparse evidence. Human-triggered SI/CPL remain legacy compatibility paths only while migration proceeds.

```text
Human goals/Tasks → Work Plane (Pi native Task Runs + Pindie semantic authority)
                         │ factual bounded Experience only
                         ▼
                 Experience store (project-local)
                         │ read-only selected evidence
                         ▼
       Learning Plane: scheduler → Discovery / Evaluation (native Pi Runs)
                         │              │
                         └→ immutable hypotheses, trials, evaluations, decisions
                                           │ trusted exact revisions only
                                           ▼
                          bounded portfolio projection → Work Plane advisory context

Reality → factual observations → Harness provenance/legality; no Learning Plane → Task truth edge
```

Human owns goals, learning budgets and exceptional override (pause, suspend, reinstate, reject); no routine promotion approval. Pi owns low-level `LLM → Tool → Result → LLM`, model invocation, tools and Session execution for all Runs. Harness owns factual selection, evidence, legality, scheduler/leases, immutable artifacts, decision gates and portfolio projection. The Discovery/Evaluation model owns semantic hypothesis meaning and evaluation, and authors bounded `useWhen`/`avoidWhen` and applicability hints in frozen packets; Harness owns only hard-fact eligibility and deterministic offer scheduling; free-form hints are not a machine classifier. The already-running Work Plane Task model owns final semantic applicability and may select/use or decline one offered experimental Strategy. Neither model owns factual provenance or authority. Reality owns reconstructable facts. Learning Plane depends on Work Plane Experience and trust-safe interfaces; Work Plane never waits for learning cognition. A small domain-specific persistent scheduler is allowed, separate from `PindieState` and the Human Task; it is neither a general task queue/workflow engine nor a second LLM loop.

## 2. Work Plane and Experience

Normal Tasks do real work and use only trusted advisory Strategy selections (or may select one explicitly labeled experimental revision when offered). Ordinary completion has **no `learningDisposition`, signal, reflection, or learning judgment**; verification, Gate and Task semantics are unchanged by learning success/failure. Task settlement writes factual episodic Experience outside `PindieState`: project namespace, operational WorkEpisodeId and Run identity, time, exact Strategy/revision selection and exposure, verification outcome and coverage, relevant tool/mutation/error/cost facts, and evidence provenance, without raw transcripts or hidden reasoning. Failure to capture Experience is an isolated diagnostic, never a reason to revise completion truth or block delivery. An experimental offer adds bounded advisory context only when an open hypothesis is actually offered; there is never a global hypothesis catalog injected into every Task. This is the only intentional Work Plane Trial integration, not a learning signal, completion disposition or post-task reflection.

Work/Experience runtime owns a small durable operational `WorkEpisodeId` (also called TaskEpisodeId) outside `PindieState`: mint once when a new semantic Task occurrence is introduced or replaced, bind to project and the observed State transition/version, retain across Runs and restart for that occurrence, close on replacement/completion. The binding ledger contains identity/open-or-closed metadata only, never a second Task status, criteria or truth source. On startup reconcile the ledger against current State and settled Experience; replay the same occurrence without reminting, close stale episodes, and if a crash leaves occurrence identity ambiguous, skip offers/Trials until a new unambiguous transition instead of assigning a duplicate. This stable boundary is a Foundation prerequisite for once-per-episode offer receipts and assignments, not a Task ID added to semantic State.

Experience is evidence, **not cognition**. Bound record size and age/count per project; validate schema and exact namespace. Retain a recent diverse window, with deterministic age/size pruning and a protected set of refs needed by unresolved hypotheses, assignments, evaluations or trust decisions. Before pruning a source needed for a continuing claim, materialize the minimal exact factual support in an immutable evidence snapshot/TrialEvidence with source fingerprint and namespace; otherwise protect it. Discovery provenance may become historical (not promotion authority) after terminal reconciliation; trial decision support stays auditable in immutable TrialEvidence/Decision even after original episodes expire. Missing required live evidence fails closed for a new decision; trusted cognition survives pruning because its exact semantics and trust evidence live in separate immutable artifacts. Never preserve unbounded raw Experience just to maintain cognition.

## 3. Learning Scheduler and durable work

The LearningJob ledger is small, bounded operational metadata, not Task State: kind (`project-discovery`, `revision-discovery`, `evaluation`, `portfolio-maintenance`, `global-discovery`), scope, deterministic input fingerprint, stable job key, state, attempt, eligible-after, budget reservation, lease owner/expiry and terminal receipt reference. States: `pending → running → completed | cancelled`; an expired `running` lease returns to `pending` with the **same key** after reconciliation. Retries preserve identity; changed corpus/portfolio/hypothesis fingerprint makes a new key. Terminal jobs can be compacted only after corresponding immutable output/receipt is resolvable; a bounded hot receipt index plus exact lookup in immutable receipts/artifacts prevents rediscovery of an old fingerprint after ledger pruning. Store commits under a single writer lock with atomic writes; one learning model Run globally at a time. Work Plane never competes for its Task semantic State. Discovery, revision-discovery, Evaluation and portfolio-maintenance model Runs (and global discovery) run only in dedicated ephemeral/internal Pi Sessions or equivalently isolated AgentSessionRuntimes owned by Host/Learning Plane, never the active Human conversation Session. Each receives only its frozen bounded packet and restricted learning tools, inherits no Human transcript, appends nothing to the Human Session and publishes only validated artifacts/receipts. Pi still owns each low-level Agent Loop.

Cheap deterministic non-LLM enqueue/reconciliation hooks run after committed Experience, at Host startup/reload and at a safe idle transition; they never wait for model learning or block Task delivery. No timer or daemon is required. At safe idle opportunity and within Human-configured per-day token/time ceilings and per-job caps, claim the oldest eligible job; reserve budget before Pi invocation, account actual usage afterward, and enforce timeout/backoff and bounded retry count. No work if quota/Host authority or evidence is incoherent. Human input, an active Human Run, or project/Session change preempts learning: abort the isolated Pi Run if safe, release lease, retain idempotent pending work or cancel stale input; never delay Human delivery. Check generation and project binding before every output commit. Learning tools are read-only except narrow immutable artifact publication; they cannot call Task semantic tools or mutate project files. No LearningJob may mutate Task/Gate/verification truth. Repeated failures or capacity pressure are visible only when actionable; ordinary discoveries do not interrupt the Human.

## 4. Local discovery and hypothesis

Trigger project discovery deterministically after a configurable minimum of **new** eligible Experience since the last terminal fingerprint, diversity across real Tasks/time/outcomes, available budget and no matching pending/running/completed key. The deterministic hooks above enqueue only when these gates pass; they do not ask a normal Task model to decide. Select a deterministic bounded corpus (e.g. stable sort by time/identity, stratified across outcomes/Tasks/Strategy exposure, per-stratum and total caps), excluding learning Runs, corrupt records and duplicates. Freeze a DiscoveryPacket: schema version, project ID, exact Experience refs and fingerprints, bounded factual summaries, selection rule/version, current trusted/open comparison catalog and fingerprints, eligibility counts, budget limits, packet fingerprint over canonical content excluding volatile timestamps. No raw Session transcript, source dump, tool-result body or hidden reasoning.

Start an independent native Pi Discovery Run with only that packet and a restricted result surface. It returns `none` or a small capped set of structured proposals. Validate exact source membership, bounds, schema, identity, advisory-only semantics and lease before atomic publication. Write a terminal DiscoveryReceipt for `none`, duplicates/covered results, or published identities keyed by packet fingerprint; retrying identical input never creates new cognition. A crash before receipt reconciles immutable outputs by job/packet key; ambiguous partial writes are quarantined, not re-created blindly. Discovery is hypothesis generation, not an assertion of novelty or trust.

`StrategyHypothesis` is immutable, exact ID and canonical semantic fingerprint (schema, scope, logical ID, kind, base revision fingerprint, fields and source refs); lineage intent is `new` or `revise` with exact parent for revision. It records project-local/user-global scope, `approach | modifier`, bounded rule/summary, `useWhen[]`, `avoidWhen[]`, **expectedEffect** (observable change under stated conditions, not a causal superiority claim), **failureSignals[]** (falsifying regressions/contradictions), applicability/trial-search hints, source Experience refs with project and record fingerprints, and discovery packet identity. Reject empty/unobservable expected effects and unfalsifiable or authority-bearing claims; semantic usefulness is model judgment. No capability, permission, safety, Gate, verification, irreversible-action or Task-authority fields are learnable. Distinct immutable revisions never overwrite each other.

A `revision-discovery` job is separately keyed by the exact prior hypothesis fingerprint, `revise` Evaluation fingerprint and bounded evidence refs/fingerprints (including TrialEvidence new relative to the original discovery). Its native Pi Discovery Run sees those frozen inputs plus the exact parent and current comparison context; it may return none or one linked immutable revision hypothesis, subject to the same provenance, falsifiability, capacity, dedupe and receipt rules. It never edits the prior hypothesis. If no new evidence is yet available, the job remains pending until a later Experience hook supplies it; changed evidence creates a new input key, and identical retries do not duplicate a revision.

Reconcile before publishing: compare canonical fingerprints for exact duplicate; bounded semantic comparison against trusted revisions and open hypotheses to mark covered/overlapping or propose revision with exact parent. Model may suggest relation, but Harness enforces identity and scope constraints, one open competing revision per lineage initially, logical ID uniqueness, and per-project/global hypothesis and portfolio caps. If unsure, record covered/needs-review rather than silently inventing IDs. At capacity, schedule maintenance or notify Human; never evict a trusted revision automatically to make room.

## 5. Lifecycle and real-task assignment

Immutable artifacts determine lifecycle, not a mutable generic strategy-status table:

```text
published hypothesis (open)
  → bounded TrialAssignment offer to real WorkEpisode
       ├─ Task model declines/does not use → factual Experience only (no eligible TrialEvidence)
       └─ Task model selects/uses (experimental while exposed)
            → eligible TrialEvidence → StrategyEvaluation verdict:
                 promote → gated StrategyDecision(promote) → trusted exact revision
                 reject  → gated StrategyDecision(reject) → rejected exact hypothesis
                 continue-testing → more real Trials (no trust Decision)
                 revise → revision-discovery → linked hypothesis or none (no trust Decision)
trusted exact revision → gated suspend / reinstate / Human override Decision
new exact revision promotion names prior trusted revision → derived superseded status
```

`continue-testing` closes only that evaluation attempt; `revise` pauses new assignments for that exact hypothesis while targeted revision discovery runs, and does not create a Decision or mutate cognition. If no revision is published, it remains untrusted and paused until bounded new evidence warrants another evaluation or an explicit exceptional Human intervention. Rejection is terminal for that fingerprint unless a new fingerprint and new evidence justify reconsideration. `experimental` is derived from valid assignment/TrialEvidence, `trusted` from an eligible promotion Decision, `superseded` from promotion of a linked exact revision naming its prior trusted revision, and `suspended` from a later Decision, never from job state. Scheduler states only track work progress. Historical decisions remain immutable and chronological; active status is a deterministic projection with integrity checks and no conflicting concurrent terminal decisions.

Do not manufacture Tasks. When open hypotheses need real Trials, the Learning Plane deterministically **offers** at most one to a new WorkEpisode before policy context is frozen, based only on hard facts: project/scope, open lineage and trust state, prior offers/attempts and cooldown, budget, fairness/rotation and any explicit machine-checkable constraints. Free-form `useWhen`/`avoidWhen` and hints inform the Task model, **not** Harness semantic matching; no hidden classifier or extra model invocation. The already-running ordinary Task model judges applicability within normal advisory policy selection and may accept/select/use or decline the offer. A bounded offer receipt keyed by project + durable WorkEpisodeId records even no-offer outcomes; no retroactive second offer to that episode. Ineligible/failed offers do not delay Task work. When no hypothesis is offerable, Task context/token cost is exactly unchanged: no experimental catalog, packet or offer text.

`TrialAssignment` is an immutable bounded **offer lease**, not proof of use: bind WorkEpisodeId, project/Session authority, exact hypothesis ID/fingerprint, optional comparison evidence refs/fingerprints when available, offer-policy fingerprint and expiry. Only while valid, present the single **explicitly untrusted experimental advisory** Strategy to the already-running Task model; it may decline. Record selection and actual exposure or factual non-use in ordinary Experience; non-selection creates no eligible TrialEvidence. No separate learning model is invoked per Task. The offer cannot enable absent tools, alter capabilities or change Task goal/verification. Replacement, cancellation, project/Session change or Human preemption invalidates the lease; if work already began, retain factual partial exposure rather than call it a completed Trial. The Task proceeds normally if offering fails. An active offer has no learning model Run competing with Human execution.

At settlement, Work Plane emits its normal Experience, including assignment ID, exact selected revision/status-at-Run, actual exposure, result/verification/cost/error facts. Learning Plane binds immutable `TrialEvidence` to **both exact hypothesis fingerprint and exact real Experience ref/fingerprint**, plus project, WorkEpisodeId for independent-Task diversity, exposure, outcome, regressions, eligibility reason and any available comparison evidence with exact provenance; no extra post-task reflection. De-duplicate by assignment + Experience; abandoned or unexposed offers are visible in Experience but yield no eligible TrialEvidence. Evaluation readiness requires deterministic minimum independent eligible Tasks, temporal/project diversity where applicable, verification-backed outcomes, genuine exposure, absence of unresolved severe regressions and bounded missing-data fraction; thresholds are versioned policy, not model-declared success. An A/B control or clean causal baseline is not required; sparse or heterogeneous support remains uncertain, never fabricated certainty.

## 6. Evaluation and autonomous trust

An `evaluation` job starts a **separate native Pi Evaluation Run**, not the Discovery Run. Freeze an EvaluationPacket with exact hypothesis fingerprint, expected effect/failure signals, eligible and excluded TrialEvidence refs/fingerprints, available comparison facts with exact refs/fingerprints (or explicit absence), independent WorkEpisode/project diversity counts, regressions, exposure/cost and current trusted/lineage fingerprints. Harness owns factual gates and provenance; model interprets whether the observations support the predicted effect and contradictions, returning exactly one verdict: `promote | continue-testing | revise | reject` with bounded semantic rationale and cited packet handles. Store immutable StrategyEvaluation (structured verdict, evidence identities, packet fingerprint, gate version); no hidden reasoning persistence. These are observational real-task Trials: promotion means evidence supports advisory use under observed applicability conditions, **not** causal superiority. Expected effects and failure signals must be observable, but no A/B control is mandatory. Expose confounding, non-use and heterogeneity in the packet; when support is weak the model must choose continue-testing, revise or reject rather than treating missing comparison evidence as proof.

`continue-testing` and `revise` are Evaluation verdicts, not StrategyDecisions. A `revise` verdict enqueues the targeted `revision-discovery` job bound to this exact hypothesis and Evaluation; neither verdict changes portfolio trust. Autonomous `StrategyDecision` is a distinct immutable trust/portfolio transition for an exact hypothesis fingerprint and Evaluation ID when promoting/rejecting; suspend/reinstate bind the exact trusted revision and fresh evidence, while exceptional Human override records actor and scope. Promotion/rejection is legal only if current gates still pass: correct advisory schema/scope, complete uncorrupted source support (live or immutable evidence snapshot) and TrialEvidence support, minimum independent real trials, no disqualifying safety/contradiction signal, frozen provenance for any available comparison evidence (and explicit absence otherwise), sufficient observational support for advisory use, portfolio capacity, no conflicting decision/suspension, no changed base revision and available budget/authority. Model recommendation alone grants nothing. Reject on strong validated contradiction under deterministic gates; insufficient/ambiguous evidence yields a continue-testing verdict or targeted revision-discovery job, not false confidence. Terminal trust write is atomic/idempotent under lock; revalidate immediately before commit. Human approval is **not** needed for routine advisory trust, but Human controls global budgets and can exceptionally pause, suspend or override through explicit audited immutable decisions. Any future authority-changing concept is outside learnable Strategy and would require separate Human-approved design.

TrustedStrategyPortfolio is a runtime projection of valid Seeds + immutable hypotheses/evaluations/decisions, bounded by scope/capacity, containing only active exact trusted revisions in normal Runs with semantics, lineage, fingerprints and provenance. Experimental revision enters only through a valid assignment, never the trusted catalog. Normal model-owned `policy_set` advisory selection remains optional; no automatic default switch. Validate malformed or conflicting trust records fail closed (omit affected learned entries, surface diagnostic); no silent fallback to an untrusted revision. Global and local trust remain distinct; local trust never implies user-global trust.

## 7. Continuous refinement, consolidation and global hierarchy

Trusted usage produces ordinary factual Experience with exact revision attribution. Harness monitoring deterministically flags factual triggers: machine-observable declared failureSignals, verification regressions, or repeated error/cost/outcome facts against versioned factual thresholds over independent WorkEpisodeIds. Semantic failureSignals require model interpretation, not a Harness assertion. These triggers enqueue an urgent isolated evaluation-mode maintenance job; the model interprets semantic effectiveness or scope mismatch from bounded evidence in a cited degradation assessment, and only that fresh assessment plus deterministic trust/scope/evidence gates may create an advisory **suspend Decision**. This trusted-usage degradation assessment is distinct from the four-verdict StrategyEvaluation of an untrusted hypothesis; it does not add a fifth verdict. Direct Harness-only suspension is exceptional: a hard objectively machine-checkable integrity/safety contract violation (e.g. corrupted exact revision fingerprint or an attempted capability/permission expansion) may fail closed and record a cited suspend Decision without semantic interpretation. Loss of evidence alone fails closed for future promotion, not invented negative proof. Suspend removes the exact revision from active projection without erasing history or altering Task truth. A revision hypothesis names the exact base; its real Trials and evaluation use the same gates. Promoting it writes one Decision naming the exact prior trusted revision; projection derives that prior revision's superseded status atomically, without a separate supersede Decision; a rejected revision leaves a still-valid base trusted unless separately suspended. Reinstatement requires a new audited decision on fresh contradictory-to-suspension evidence and current safety gates, or promotion of a new revision; no expiry-based automatic reinstatement.

Low-frequency `portfolio-maintenance` jobs examine bounded trusted/open catalogs plus supporting evidence for overlap, duplicates and fragmentation. A consolidation proposal is an ordinary falsifiable hypothesis with lineage and baseline identities; it must obtain real Tasks, Evaluation and Decision, never rewrite/merge live Strategies directly. On full capacity, stop publication/promotion and report actionable pressure rather than silently evict history or an active Strategy.

Global discovery is **later-stage hierarchy**: local Experience → local discovery/trial/evaluation first. `global-discovery` consumes bounded conclusions from multiple independent **active trusted** project-local revisions (with valid promotion Decisions) **and** exact minimal supporting TrialEvidence/source provenance, not a raw multi-project Experience dump. Its packet freezes contributing project identities, exact active local revision/Decision fingerprints, diversity and comparison context; experimental local hypotheses are ineligible inputs. A global hypothesis has user-global scope but no global trust; test on suitable future real Tasks in multiple other projects, with explicit cross-project diversity and conflict gates. Local trust stays local; global trust is a new separately evaluated/decided scope. The legacy CPL v0.1 transfer and v0.2 synthesis artifacts retain their existing Human decision semantics during migration; do not reinterpret old approvals as v1 autonomous decisions or erase them.

## 8. Artifact families, integrity and recovery

| Family | Role | Persistence |
| --- | --- | --- |
| Experience | factual episodic evidence | bounded, prunable, namespace-scoped |
| WorkEpisodeId binding ledger / LearningJob / DiscoveryReceipt / offer receipt | operational identity, scheduling and dedupe, **not cognition or Task truth** | bounded durable ledger/receipts |
| StrategyHypothesis | immutable falsifiable cognition proposal | exact ID/fingerprint, append-only |
| TrialAssignment | immutable real-Task lease binding | bounded lease history |
| TrialEvidence | immutable factual trial summary/provenance | append-only, protect decision support |
| StrategyEvaluation | immutable `promote | continue-testing | revise | reject` verdict with cited facts; no trust transition | append-only |
| StrategyDecision | immutable gated promote/reject/suspend/reinstate or explicit Human override; revision promotion names superseded exact revision | append-only |
| TrustedStrategyPortfolio | derived runtime projection, **not a store** | reconstruct on demand |

All artifacts are schema/versioned, size-bounded, namespaced, canonical-hashed and written exclusively after full validation; lock and atomic rename/unique creation guard concurrent writers. On restart, expire leases, reconcile job keys against receipts and exact outputs before retrying; never count a prior Pi response as committed cognition without its validated artifact. Duplicate delivery returns the same identity/result. Stale Session/project/generation discards uncommitted output. Interrupted Discovery/Evaluation resumes as the same job only after reconciling prior outputs; ambiguity/quarantine or malformed stores blocks that affected scope rather than fabricating a fresh result. An interrupted Trial never becomes eligible solely because an assignment exists. Partial/ambiguous writes fail closed; Human work is unaffected. Enforce single active learning Run across processes via durable lease/fencing; scheduling may continue after restart, not run duplicate cognition. No background daemon is necessary: safe idle Host opportunities suffice.

Budget per job, per day and per scope; packet/portfolio/record limits and exponential bounded backoff are versioned Human-configurable policy. No per-Task reflection tax. Notify only for repeated failures, exhausted budget needing Human action, capacity, corruption or exceptional override; do not announce each discovery/evaluation.

The removed `learning-opportunity.ts` assessed a single accepted signal after settlement; old operational receipts, if present, remain on disk but are no longer read. CPL v0.2 currently synthesizes from qualified multi-project raw Experience; replace future global discovery input with local conclusions plus exact supporting evidence. ## 10. Dependency-ordered implementation and acceptance

1. **Compatibility audit and clean Work Plane (complete):** read-only audit existing stores and trust bindings; remove single-Run `learningDisposition`, signal/holder, admission and prompt/capability wiring early, before Discovery/Trials. Preserve factual Experience and legacy SI/CPL artifact readers as needed; update current docs/tests in that implementation slice. Ordinary completion becomes learning-free.
2. **Foundation:** establish restart-stable WorkEpisodeId bindings outside State before Trials; freeze v1 schemas/identities, factual Experience protection, strict stores and portfolio migration rules; add bounded persistent scheduler/locks/budget/preemption, isolated internal Pi Sessions and crash/idempotence tests.
3. **Local discovery:** nonblocking deterministic enqueue hooks, corpus triggers, deterministic packet/receipt and isolated native Pi Run; test none/duplicate/restart, no ordinary Run tax.
4. **Hypothesis/reconciliation:** validate falsifiability, fingerprint/lineage, comparison and bounded identity growth; publish inactive hypotheses.
5. **Real-task trials:** once-per-WorkEpisodeId hard-fact offer and Task-model selection, offer lease, bounded experimental context and factual attribution/TrialEvidence; fail open for Task progress, closed for trust.
6. **Evaluation/trust:** isolated Evaluation Run and exact four-verdict schema, diversity gates, gated immutable promote/reject Decisions, targeted revision-discovery jobs for revise, continued real Trials for continue-testing, trusted projection and Human override.
7. **Refinement/maintenance:** urgent semantic Evaluation before normal suspension, exceptional integrity-only direct suspension, revision/supersession/reinstatement and evidence-backed consolidation; capacity behavior.
8. **Global hierarchy:** independently trusted active local revisions with exact support, cross-project real offers/evidence, global evaluation and separate user-global Decisions; preserve legacy trust until explicit data migration.
9. **Long-running dogfood:** budget/preemption, restart, pruning, trustworthy revision and multi-project applicability on actual Human development Tasks before claiming operational success.

Acceptance: when no experimental hypothesis is offerable, normal Tasks see no learning tool, reflection requirement, discovery packet or added learning context/token cost beyond their existing trusted-policy baseline; accumulated real Experience yields a useful falsifiable hypothesis; at most one untrusted hypothesis is offered to a future real WorkEpisode by hard-fact eligibility and only a semantically suitable offer is selected by its ordinary Task model; independent factual Trials accumulate; Evaluation verdicts lead to gated autonomous advisory promotion/rejection or targeted revision discovery without direct rewriting; active trusted exact revisions influence future normal selection without expanding authority; later contradictions suspend or lead to revision/supersession; pruning leaves auditable trusted cognition; restart/preemption neither loses jobs nor duplicates cognition. Instrument counters/latency and test fail-closed corrupt evidence, conflicting Decisions, stale Session and budget exhaustion. These are release/dogfood gates, not claims that v1 exists today.
