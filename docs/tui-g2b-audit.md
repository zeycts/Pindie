## Critical findings

- **A03 — FAIL / P2:** actual G2b dogfood observation: Header/Footer lack left/right zoning. On main, `formatHeader` and `formatFooter` concatenate fields into one left-origin string; `BoundedSingleLineText.render` truncates the *entire* line at width, so model/thinking and late status/action hints disappear instead of retaining a right-side anchor. Existing tests assert row/width bounds, not zoning. P2: persistent discoverability/readability regression, but no evidenced data loss or authority bypass. Existing candidate PR #178 must remain unmerged and must not turn this main verdict into PASS.
- **No confirmed P0/P1** from static evidence. This is not a claim that runtime dogfood has none; absent real terminal and end-to-end coverage remain explicit gaps.

## Coverage gaps

- Ten ordered journeys below are **reasoned traces**, not ten end-to-end automated tests. Unit/controller/remote fixtures exercise seams independently; no single fixture proves cross-surface temporal ordering through actual Pi runtime + terminal + Discord. In particular, real successor settlement and recovery/rebind are not established by a green suite.
- `PindieTuiView.apply` rebuilds Timeline on each refresh and formats all projected blocks (`src/tui/view.ts:929-984,1378-1389`); no long-session memory/CPU/frame latency or scrolling-under-stream load measurement. Performance verdict A38 is NOT COVERED, not FAIL.
- Input region uses Pi `Text` for Gate question/options, soft blocker, notice and Extension widgets (`src/tui/view.ts:1410-1448`); narrow-width frame checks do not prove low-height terminal readability/scroll access or subjective information hierarchy. No real IME, paste, upstream Alt-key, tmux detach/reattach, cursor restoration, or resize-under-interaction proof.
- Raw runtime/extension errors can reach notices (`src/tui/pindie-interactive-mode.ts:185-189,268-279,310-354`; `src/tui/view.ts:1410-1448`); no comprehensive wording/debug-leak review for arbitrary error strings. Do not infer a proven leak solely from error rendering.
- Full Extension compatibility is explicitly limited by public Pi APIs: factory widgets, headers/footers, `custom`, custom editor and theme APIs throw unsupported (`src/tui/extension-ui.ts:215-240`). PASS for truthful rejection only, **not** full compatibility or G2c sign-off.

Record regressions as new evidence; no bug fix in this audit.

## Recommended fix clusters

2. **Interaction and terminal realism (A06–A07, A34, A37, F10):** actual SSH/tmux/IME/paste/resize/focus/cursor observations before assigning usability PASS; add coverage only in a later scoped task.
