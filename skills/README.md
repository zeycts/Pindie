# Pindie Skills

Pindie Skills use Pi-compatible `SKILL.md` files and are optional specialized development procedures. Add one only after repeated real use has revealed a narrow, reusable procedure.

A Skill specializes the Pindie Core Loop; it does not reproduce or replace it. It remains subordinate to current user intent, observed project reality, the Task Contract, Verification, Human Gates, and Pindie hard invariants. Skills do not maintain persistent Skill-local workflow state.

`references/`, `scripts/`, and other supporting resources are optional; load them only when needed. A Skill description should clearly state what it does and when to use it.
